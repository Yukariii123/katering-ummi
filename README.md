# katering-ummi

A catering business website for showcasing food services and packages.

## Overview
This repository contains a static business website for a catering company. It is designed for service promotion and menu presentation.

## Features
- Landing page design
- Services/product showcase
- Business presentation layout
- Responsive front-end design

## Tech Stack
- HTML
- CSS
- JavaScript

## Getting Started
1. Clone the repository.
2. Open `index.html` in your browser.
3. Or use a local server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
